## 二、drag 区吞点击 — 复现成功，立案 P2-2501

- 复现步骤：还原窗口并 resize 至 ~900×520 → Settings→通用 向下滚动使「长按模式 RightCtrl」select 进入窗口顶部 40px 带（点击点约 y=25px）→ 点击无任何响应（不弹下拉，区域变为可拖拽）；把同一控件滚回正常位置点击立即弹出。
- 根因：App.tsx L124 `.drag fixed inset-x-0 top-0 z-50 h-10` 全宽覆盖顶部 40px，仅右上三个窗口按钮 no-drag；任何滚入该带的可交互元素点击均被窗口拖拽吃掉。真实用户小窗口 + 滚动场景必然命中，属通用可用性问题。
- 证据：ss_8c320287.png + ss_zoom_90d87fd8.png（顶部带点击无效）、ss_zoom_18a50c68.png / ss_zoom_14a7b356.png（正常位置对照有效）。
- 建议方案（成本极低）：① 首选给主内容滚动容器加 `no-drag`（一行 class），drag 条实际可拖区收敛为侧栏顶部与右上按钮左侧空白；或 ② drag 条只铺 `left-0 right-36` 之外再排除内容区。两者都不需要重构。

## 三、挂账论证

### 3a. 本地自动分段/格式化原型 — 值得做，建议下轮单维度原型
- 收益：无 LLM 时长语音（免按模式几分钟连续口述）目前落字为整块文本，可读性差；自动分段（按停顿时长阈值 + 句末标点在 finalize 边界插空行）直接改善主场景体验，且是纯本地、离线卖点的自然延伸。竞品对照：Handy 无任何格式化维度；Wispr Flow 格式化全靠云端——本地分段是差异化落点（沿 248 轮结论）。
- 成本：低。dictation 管线已有分段 finalize 事件与停顿切分（246 轮 0.3s 次级补切基建），在落字层按「finalize 间隔 > N 秒 → 插入换行」即可起步，估 0.5~1 轮含回归。
- 结论：**立项做单维度原型（自动空行分段）**，列表化/模板等维度等原型验证后再扩展。

## 五、竞品对照：新增两个高价值差距（上轮两项维持挂账不展开）

1. **自动语言检测/模型路由**（对照 Handy、superwhisper 的 auto language detect）：SpeakType 现在语言能力绑定在用户手选模型上（parakeet 不支持中日韩粤），说另一种语言需手动切模型（且历史上切模型是重灾区）。中期方向：首段音频过轻量语言 ID → 自动路由到对应已下载模型；短期低成本替代：识别结果乱码特征检测 → 提示「当前模型不支持该语言，点此切换」。
2. **听写中本地命令词**（对照 Aqua Voice voice-native editing 的子集）：免按长口述时说「删掉刚才那句」「换行」目前都会被原样落字。纯本地小词表命令（换行/删上一段/撤销）不依赖 LLM，与本地分段（3a）共用 finalize 边界基建，可作为其后续维度。
