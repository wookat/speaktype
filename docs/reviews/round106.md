## ② 音频输入边界专项

1. **指定设备消失（micDeviceId 指向不存在设备）【实测】过**：注入 bogus deviceId 重启后 RightCtrl 听写——静默回退系统默认麦克风，落字「今天下午3点开会，预算是5200元」含 ITN 完整无损；设置页麦克风下拉优雅回显「自動検出（システム既定）」不显示脏值。回退无提示属合理取舍（用户无感恢复）【源码 recorder.ts:57-59】。
2. **无任何捕获设备（禁用唯一麦克风后听写）【实测】过**：按 RightCtrl → 会话即取消 + 本地化 toast「マイクを使用できません — マイクが見つかりません」（micUnavailable/micNotFound，ja 实拍），无残留胶囊、无崩溃、log 无异常。
3. **录音进行中设备被禁用（拔插近似）【实测】过**：Alt+Q 免提播音进行中于系统面板禁用 CABLE Output——断点前已捕获音频正常出字（finalize voicedMs=5380），下一轮开麦失败弹同款 micNotFound toast、悬浮胶囊正常退出**不卡死**；重新启用设备后无需重启应用，听写立即恢复。
4. **muteWhileRecording【实测】过**：CoreAudio 轮询默认输出端点静音位——录音开始 ~0.7s 内 muted=False→True，松手后 True→False 精确还原（12 点采样时间线）。注：虚拟声卡 render 通路不受端点静音影响导致回环采集仍有信号，属虚拟驱动特性非产品缺陷；真实扬声器场景该开关即静音媒体。
5. **采样率/声道异常输入【实测】过**：捕获端点 48kHz/24bit/立体声（系统面板核实），管线 16kHz/mono 重采样（AudioContext sampleRate:16000 + channelCount:1【源码】）长期日常全部听写正常，无变调/丢字。
6. **听写中切换默认设备（多设备热切）【未验证】**：本机仅一个捕获设备无法实测；【源码推断】流在会话开始时抓取并持有，录音中切默认不影响已开流，下一次会话按新默认开麦。

观察①（不立案）：无麦克风时 toast 提示准确，但设置页麦克风下拉在设备为空时仍只显示「自动检出」无「未检测到设备」态；低频且 toast 已兜底，仅记录。
