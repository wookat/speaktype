### P3-①【实测】转录结果不持久：重启应用即静默丢失，且不入历史

- 复现：转录完成（结果已上屏）→ 不导出 → 退出应用 → 重启 → 转录页回到空态，结果无处可寻；历史页也只有听写条目、无转录记录（实拍两处）。
- 论证：转录 3 小时音频可能耗时几十分钟，用户关掉应用（或 Windows 更新重启）即全部作废且无任何提示——「静默丢失族」；对比 MacWhisper 会话可存 .whisper 文件、全文可搜【官方】。因可重跑、且导出动线明显 → P3 不升 P2。
- 修法建议（~30 行）：主进程把最近一次完成的 TranscribeState（含文件名）落盘 userData/transcribe-last.json，启动时恢复到页面并标注「上次转录」；或至少退出时若有未导出结果弹确认。

### P3-②【实测】官网正文零文件转录内容，v0.14 旗舰卖点只有 hero 徽章一句话

- 复现：en 与 /zh/ 全页核对——功能九宫格、「一分钟上手」、对比表、FAQ 均无文件转录；对比表甚至没有「文件转录」行（这正是我们第 76 轮矩阵里对 Superwhisper 的失分项，现在做了却没写上去）。
- 论证：官网是获客入口，旗舰新功能只在顶部徽章一句话，搜「音频转文字/转 SRT」需求词的用户完全感知不到；属发布配套缺口，改文案零产品风险 → P3。
- 修法建议：功能格加一卡（拖入音视频 → 离线转文字 → 导出 TXT/SRT）；对比表补「文件转录」行；FAQ 补一条；hero 副文案或截图带上转录页。

## ③ 竞品转录体验对比（基于第 76 轮矩阵 + 本轮 MacWhisper 官方页核对）

MacWhisper（Gumroad 官方页 2026-08-16 查询，53 万销量、4.5 分）是文件转录的标杆【官方】；Wispr Flow 只有会议记录（云端）【官方】；Handy 无文件转录【第 76 轮实测】。

| 能力 | SpeakType v0.14【实测】 | MacWhisper【官方】 | 差距评估 |
|---|---|---|---|
| 拖放转录 | 有 | 有 | 持平 |
| 完全离线 | 有 | 有 | 持平 |
| 中文质量 | SenseVoice 中文特化 | whisper 通用 | **我们占优** |
| 导出 | TXT/SRT | srt/vtt/csv/docx/pdf/md/html/.whisper | 落后（长尾格式） |
| 结果持久/可搜 | **无（P3-①）** | .whisper 会话文件 + 全文搜索 | **落后（核心）** |
| 播放联动/段编辑 | 无 | 音频回放同步 + 段编辑/星标 | 落后 |
| 说话人分离 | 无 | Pro 本地说话人识别 | 落后（需新模型，暂不建议） |

| 价格 | 免费 MIT | 免费版+Pro $75 买断 | **我们占优** |

**结论**：v1 转录已站住「拖放→离线→导出」最小闭环，中文与免费开源是差异化；下一步最高 ROI 是 **结果持久化（P3-①）→ 段编辑+播放联动 → 批量转录**；说话人分离/YouTube 等属远期。
