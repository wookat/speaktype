## 2. 悬浮条状态流转【实测】

- **录音态**：人设 chip（面对老板）+ 实时波形 + X 取消钮 + 上方实时字幕 partial 滚动（实拍）。
- **转写态**：松手后 chip + 旋转 spinner「转写中…」（实拍）；本地 parakeet 转写快，该状态通常一闪而过。
- **X 取消**：脚本化在录音中点 X（真实鼠标事件、hold 键保持按下）——**完全丢弃**：无 finalize 日志、无历史条目、无落字。
- **录音中点击别处不打断**：脚本化保持 RightCtrl 按下同时鼠标点击他处——录音持续、整句完整落字（GetAsyncKeyState 实查按键仍按下）。注：用「电脑用」工具直接点击时录音会提前结束，那是自动化注入前先释放修饰键的**测试工具伪影**，非产品行为，已用纯脚本对照实验排除。
- **落字位置**：落到松手时焦点编辑器的光标处（含中键点击移动光标后插入文中间），行为正确。
